# 0호선 — 효과 융합 로그라이크 RPG

존재하지 않는 승강장에서 출발하는 검은 열차 **0호선**을 배경으로 한 모바일 우선 정적 웹게임 프로토타입입니다.

객차에서 전투하고 보상으로 얻은 **잔향(기본 효과)**을 조합해 1차 → 2차 → 궁극 융합을 완성하는 것이 핵심입니다.

## 현재 구현

- 0호선 인트로 및 열차 세계관
- 객차 20종
- 객차마다 별도의 환경 규칙 / 적 / 보스
- 한 객차당 6스테이지, 마지막 스테이지 보스전
- 객차 클리어 후 다음 객차 3택
- 턴제 전투: 공격 / 수비 / 신중한 일격 / 초신속
- 적의 다음 행동 예고
- 전투 승리 후 잔향 장비 3택 + 골드 새로고침
- 기본 효과 32종, Lv.1~10
- 1차 융합 64종
- 2차 융합 32종
- 궁극 융합 12종
- 발화 / 출혈 / 독액 / 감전 / 냉기 / 저주 / 사령술 / 영혼 / 혈마법 등 실제 전투 적용
- 브라우저 `localStorage` 자동 저장
- 발견한 융합 도감은 사망 후 새 회차에도 유지
- 모바일 세로 UI

## 중요한 보상 규칙

**객차와 효과 보상은 완전히 분리되어 있습니다.**

망자의 객차라고 사령술 확률이 오르거나, 붉은 화물칸이라고 발화 확률이 오르지 않습니다. 모든 전투 보상은 항상 **기본 효과 32종 전체 풀**에서 무작위로 추첨됩니다.

객차는 오직 아래 요소만 담당합니다.

- 환경 / 분위기
- 전투 기믹
- 등장 적과 보스
- 난이도와 골드 등 전투 보정

## 융합 규칙

- 1차 융합: 필요한 기본 효과 2개가 각각 Lv.3 이상
- 1차 융합 Lv.2: 두 재료가 각각 Lv.5 이상
- 1차 융합 Lv.3: 두 재료가 각각 Lv.7 이상
- 1차 융합 Lv.4: 두 재료가 각각 Lv.10
- 2차 융합: 필요한 1차 융합 2개가 각각 Lv.2 이상
- 궁극 융합: 필요한 2차 융합 2개가 각각 Lv.2 이상
