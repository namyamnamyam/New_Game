# New_Game — 융합 로그라이크 프로토타입

스토리 없이 전투/보상/효과 융합만 먼저 구현한 모바일 우선 정적 웹게임 프로토타입입니다.

## 현재 구현

- 턴제 전투: 공격 / 수비 / 신중한 일격 / 초신속
- 적 행동 예고 및 정예전
- 전투 승리 후 장비 3택 + 골드 새로고침
- 기본 효과 32종, Lv.1~10
- 1차 융합 64종
- 2차 융합 32종
- 궁극 융합 12종
- 대표 융합 효과의 실제 전투 상호작용
- Act 6스테이지 반복 구조
- 브라우저 localStorage 자동 저장
- 모바일 세로 UI

## 융합 규칙

1차 융합은 필요한 기본 효과 2개가 각각 Lv.3 이상일 때 자동 활성화됩니다.
2차 융합은 필요한 1차 융합 2개가 활성화되면, 궁극 융합은 필요한 2차 융합 2개가 활성화되면 자동 활성화됩니다.

## GitHub Pages

저장소 Settings → Pages에서 `Deploy from a branch`, `main` / `/ (root)`를 선택하면 정적 페이지로 실행할 수 있습니다.
